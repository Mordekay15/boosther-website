# BoostHer website

Landing page for **BoostHer**, the Turku entrepreneurship community empowering women and minorities to become entrepreneurs.

It is a static site with no build step. Open `index.html` in a browser, or deploy the folder as-is (GitHub Pages, Netlify, etc.).

```
index.html        page markup and content
styles.css        brand tokens, layout, animations
script.js         mobile nav, subtle scroll reveals
assets/           Boost wordmark (red/white), partner logos, favicon
assets/photos/    event photos (800px + 1600px, metadata stripped)
```

## Brand
Taken from the BoostHer brand guidelines:

| Token | Hex |
|---|---|
| Boost red | `#C4161C` |
| Her blue | `#0E2D73` |
| Background rosa | `#FFDBDC` |
| Dusty rose | `#DFBABB` |
| Background gray | `#E9E6E6` |
| Background beige | `#F5E8D9` |
| Purple brown | `#4D080A` |

Fonts: **Playfair Display** for headings, **Source Serif 4** for body text (a web-friendly stand-in for Times New Roman), **Pinyon Script** for the "Her" script (a free stand-in for TS Kaewpet NP), and **Montserrat** for small caps labels.
